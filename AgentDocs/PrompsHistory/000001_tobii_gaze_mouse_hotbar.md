Date: 2026-06-06

## Original Prompt

```text
Create program for window that will use tobbi eye tracker 4c for simulating mouse movement. 
It must be python program which can be boundled in .exe file. 
When that program is opened has to create hotbar on top of the screen, which has to push eveyrthing on the screen down,
essencally has to split screen, while allowing mouse movement on both. Now using tobii eye tracker 4c (which is connected to the device)
it has to simulate mouse movement!

On this top screen hotbar, it must be placed in the center by width, and top by height, it must have following buttons for Now
Left click, Right Click, Double left click, speach, keyboard, settings. Add some nice icons in them (find some librabry) which will fit the pourpose
When left click is selected, position at screen where it's stared it has to do left click
When right click is selected, position at screen where it's stared it has to do right click
When double left click is selected, position at screen where it's stared it has to do double left click

Do those for now, dont boundle the .exe file yet, just make it python scripts. 
```

## What Was Done

- Added a Python/PySide6 desktop app in `gaze_mouse/`.
- Added `run_gaze_mouse.py` as the launch script.
- Added `requirements.txt` with:
  - `PySide6`
  - `pyautogui`
  - `qtawesome`
  - `tobii-research==2.1.0`
- Added `README.md` with Windows install/run instructions and current limitations.
- Implemented a top frameless toolbar with centered buttons:
  - Left click
  - Right click
  - Double click
  - Speech
  - Keyboard
  - Settings
- Added icon support through `qtawesome`, with Qt standard icon fallbacks if `qtawesome` is missing.
- Added Windows AppBar reservation through `ctypes`/`SHAppBarMessage` so the toolbar reserves the top work area instead of covering maximized windows.
- Added Tobii gaze streaming through `tobii_research.find_all_eyetrackers()` and `subscribe_to(EYETRACKER_GAZE_DATA, ..., as_dictionary=True)`.
- Added gaze smoothing and screen-coordinate mapping.
- Added mouse movement and click simulation through `pyautogui`.
- Added dwell behavior:
  - Looking at toolbar buttons activates them.
  - Looking at a target after selecting left/right/double click fires the click.
  - Click mode resets after one fired click to reduce accidental repeat clicks.
- Added Settings dialog for dwell time, dwell radius, cooldown, smoothing, and mouse movement enable/disable.
- Added Keyboard behavior to launch Windows `osk.exe`.
- Added `Ctrl+Q` shortcut to close the app.
